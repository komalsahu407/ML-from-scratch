# Customer Segmentation using K-Means

This project uses **K-Means Clustering** to group customers based on their **age and income**.

## Features

* Data visualization using Matplotlib
* K-Means clustering with 3 clusters
* Customer group visualization

## Technologies

* Python
* Pandas
* Matplotlib
* Scikit-learn

## Algorithm

**K-Means Clustering** — an unsupervised machine learning algorithm used to divide data into similar groups.

## Project Type

**Machine Learning | Unsupervised Learning | Clustering**
