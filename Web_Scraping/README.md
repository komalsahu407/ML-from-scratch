# Web Scraping and Sentiment Analysis

This project collects movie reviews from the web and performs basic sentiment analysis on the collected reviews.

## Project Overview

The project searches for movie reviews using DuckDuckGo, extracts review text from web pages, cleans the text, and classifies the reviews as **Positive, Negative, or Neutral**.

## Technologies Used

* Python
* Pandas
* BeautifulSoup
* urllib
* DuckDuckGo Search
* AFINN

## How It Works

1. Enter a movie name.
2. Search for movie review pages.
3. Extract text from web pages.
4. Clean the collected review text.
5. Apply AFINN sentiment analysis.
6. Classify reviews as Positive, Negative, or Neutral.
7. Count the total reviews in each category.

## Concepts Used

* Web Scraping
* Text Cleaning
* Sentiment Analysis
* Natural Language Processing (NLP)
