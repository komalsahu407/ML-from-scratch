# Decision Tree

This folder contains machine learning projects based on **Decision Tree algorithms** for classification and regression tasks.

## Projects

### 1. Decision Tree Classification

* Dataset: Iris Dataset
* Task: Classification of flower species
* Model: `DecisionTreeClassifier`
* Accuracy: **98%** (initial model)

### 2. Decision Tree Regression

* Dataset: California Housing Dataset
* Task: House value prediction
* Model: `DecisionTreeRegressor`
* Evaluation: R² Score

### 3. Loan Approval Prediction

* Task: Predict whether a loan application will be approved
* Model: `DecisionTreeClassifier`
* Criterion: Entropy
