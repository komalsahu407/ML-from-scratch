# Loan Approval Prediction using Random Forest

This project predicts whether a loan application will be **Approved** or **Rejected** using the **Random Forest Classifier**.

## Project Overview

The project analyzes loan application data and uses a Random Forest model to predict loan approval status.

## Algorithm

* Random Forest Classification
* `RandomForestClassifier`
* 300 Decision Trees
* Entropy criterion

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Tkinter

## Features

The model uses information such as:

* Number of Dependents
* Education
* Self Employment
* Annual Income
* Loan Amount
* Loan Term
* CIBIL Score
* Residential Asset Value
* Commercial Asset Value
* Luxury Asset Value
* Bank Asset Value

## Model Evaluation

The model is evaluated using:

* Accuracy
* Confusion Matrix

## Prediction

The project also includes a **Tkinter GUI** where users can enter loan application details and get a prediction:

* Loan Approved
* Loan Rejected
