# OpenCV Computer Vision

This project contains basic **Computer Vision** experiments using **OpenCV** and Python.

## Project Overview

The project covers basic image and video processing along with face and eye detection using Haar Cascade classifiers.

## Features

* Read and display an image
* Read and process video frames
* Convert video frames to grayscale
* Detect faces using Haar Cascade
* Detect eyes using Haar Cascade
* Draw bounding boxes around detected faces and eyes

## Technologies Used

* Python
* OpenCV
* NumPy

## Concepts Used

* Image Processing
* Video Processing
* Grayscale Conversion
* Haar Cascade Face Detection
* Haar Cascade Eye Detection
