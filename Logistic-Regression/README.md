# 💳 Credit Card Fraud Detection using Logistic Regression

## 📌 Overview

This project uses Logistic Regression to detect fraudulent credit card transactions.

The dataset contains transaction-related features, and the target variable `is_fraud` is used to classify transactions as fraudulent or non-fraudulent.

## 🎯 Objective

To build a Logistic Regression classification model for detecting fraudulent credit card transactions.

## 🤖 Model Used

- Logistic Regression

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

8. Feature and Target Separation
9. Train-Test Split
10. Logistic Regression Model Training
11. Prediction
12. Model Evaluation

## 🔑 Target Variable

is_fraud

The target variable is used to identify whether a transaction is fraudulent or non-fraudulent.
